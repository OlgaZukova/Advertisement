# Advertisement
Typa the Advertisement on the screen.
This project is a simple interactive web page built to demonstrate and practice JavaScript’s charAt() method.
![image](https://github.com/user-attachments/assets/faa787c8-b70d-4aee-92d3-703b8637244f)
The web application allows users to input a string and a character index, then displays the character found at that index using the charAt() method.
index.html:The main structure of the page, including the input form and display area.
style.css:Provides styling to the page elements for better visual presentation.
index.js:Contains JavaScript logic that reads user input, uses charAt() on the string, and shows the result dynamically.
